# 小红书图文笔记拆解 Skill

用于拆解小红书图文笔记的 AI Skill，支持多图截图整理、互动数据核对、标题与封面分析、内容结构拆解，提炼可复用的创作模板，并说明证据来源和适用条件。

## 能做什么

- 按五步框架分析数据、标题、封面、内容结构和可复用点。
- 根据轮播页码与正文衔接整理截图，区分笔记配图与内嵌评论、聊天材料。
- 核对数据来源与差异，区分页面缩写和精确计数。
- 按实际内容类型分析经历、观点或教程，不统一套用清单。
- 输出标题公式、原创标题变体、内容骨架及下一篇的行动建议。

## 获取与使用

下载本仓库，或运行：

```bash
git clone https://github.com/wur4239-art/xiaohongshu-note-breakdown.git
```

将完整目录作为技能交给支持 `SKILL.md` 的 AI 工具，按该工具的技能加载方式启用；保留 `references/` 的相对路径。也可以在对话中提供 `SKILL.md`，明确要求按照其中的流程分析笔记。

本仓库提供分析指令，不是独立运行的应用，也不是小红书登录或抓取工具。截图分析需要所用 AI 工具支持图片理解。

## 使用示范

> 帮我拆解这篇笔记，标题是《主体性强的人，上班根本不内耗》，点赞1万，收藏5000，评论300，职场领域。

可以继续补充笔记链接、首图、正文截图、评论区截图及发布时间。信息不全时，仅分析已知内容；链接要求登录或无法访问时，不假装读取全文。

默认交付：五步拆解、质量总结、可复用公式与行动清单。需要评分时可另外说明。

## 分析边界

区分已知事实、分析推测和原创建议；不编造正文、封面或评论，不从点赞量推断曝光或流量来源。个人经历与聊天片段仅支持有限观察，复用建议需保留适用条件，不保证成为爆款。

## 验证情况

技能格式校验已通过，已进行标题与数据输入、链接受限、截图分析等单案例试运行及自检。根据截图实测补充了来源归属、数值精度和内容类型等规则。

`references/regression-cases.md` 提供10个维护验证案例。新增规则尚未逐项完成行为回归测试；格式校验不等于效果验证。仓库不包含原始笔记截图或私人聊天附件。
