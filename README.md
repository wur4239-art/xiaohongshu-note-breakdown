# 小红书图文笔记拆解与模板提炼

分析单篇或多篇小红书图文笔记，拆解封面、标题、正文和互动数据，提炼带填空位的创作模板与仿写示范。

## 使用方法

下载仓库，保留 [SKILL.md](SKILL.md) 和 [分析框架](references/note-analysis-framework.md) 的相对路径。按所用 AI 工具的方式加载技能 `xiaohongshu-note-analysis`。分析截图时需要工具支持图像读取。

提供笔记截图、链接、标题、正文或互动数据，然后说明你希望进行单篇拆解、多篇对比还是定向仿写。

> 帮我拆解这篇小红书笔记，分析封面、标题和正文结构，并提炼一个可以填空复用的创作模板。
