# 回归验证案例

用于维护技能时检查来源、计算与结构判断。比较实际行为与下列要求，不匹配固定措辞。记录测试输入、实际输出、通过／未通过及限制，不把格式校验当作行为验证。

| 案例 | 输入 | 应观察的行为 |
| --- | --- | --- |
| 仅标题与数据 | 主体性强的人，上班根本不内耗；点赞1万、收藏5000、评论300 | 分析已知标题；说明数字来源和万单位口径；不编造封面、正文和评论内容 |
| 数据冲突与嵌套材料 | 示例收藏5000、评论300；截图显示点赞“1万”、收藏4593、评论226；首图内评论显示2038与740点赞 | 采用截图描述该快照并列明差异；比例以10000估算时为约45.93%、约2.26%；不合并内嵌点赞，不称为本篇热评 |
| 多图顺序与类型 | 6张附件中有4张轮播配图，正文开头重复；正文三节为性格边界、情绪价值、配得感，含经历与聊天 | 去重并区分两种数量；根据页码与衔接排序；识别经历／观点混合类型，不套成六页教程 |
| 时间混淆 | 状态栏23:36；发布区域2025-5-13；截图采集日期未知 | 只认定可见发布日；不称23:36为发文时刻，不计算积累速度 |
| 零点赞 | 点赞0、收藏10、评论2 | 藏赞比与评赞比标注无法计算，不除以零，不写无限大，不用0分替代证据判断 |
| 缺少封面 | 有正文，无图片 | 可以分析文字结构；封面与图片视觉无法评估；建议方案与原文观察分开 |
| 登录受限 | 分享短链跳转至详情，详情又跳转至登录页，最终返回HTTP 200 | 不将200当正文成功，不称短链失效；说明限制，继续分析已有材料 |
| 后台精确值 | 同一时点后台点赞12000、收藏4593、评论226 | 藏赞比约38.28%、评赞比约1.88%；不沿用以10000估算的比例，不混用不同时点数据 |
| 首图与点击效果 | 只有详情页第一张图，无信息流与后台数据 | 分析可见设计，说明裁切未知，不报告实测点击率；默认质量总结，无随意总分 |
| 迁移边界 | 作者自述有经济余量，展示一次沟通后对方缓和的片段 | 保留自述与适用条件；不证明普遍因果或长期效果；不将作者经历写成用户亲历 |

复杂截图案例来自本次会话的用户材料。技能包不包含原始截图，若执行视觉回归，应使用可访问的原附件；缺少附件时只能验证表内简化输入，不能声称完成了原图视觉测试。
