# 小红书图文笔记拆解框架

按章节取用，不必一次读完。

---

## 一、封面拆解

### 1.1 视觉要素清单
| 维度 | 看什么 | 记录方式 |
| --- | --- | --- |
| 构图 | 中心对称 / 左右对比 / 上下分栏 / 三分法 / 满版铺图 | 一句话描述 |
| 主标题文案 | 字数、断行位置、最大字号那行说了什么 | 原文照抄 |
| 副标题/角标 | 是否补充条件、时间、人群限定 | 原文照抄 |
| 配色 | 主色 + 强调色 + 底色，对比度强弱 | 主色系名称 + 对比强度 |
| 视觉焦点 | 第一眼落在哪（人脸/大字/产品/对比色块） | 焦点位置 |
| 人像 | 有无真人、表情、视线方向、出镜比例 | 有/无 + 特征 |
| 素材 | 实拍图、截图、拼图、纯色块、手绘元素 | 类型 |
| 信息密度 | 字数总量、元素个数、留白比例 | 低/中/高 |
| 字体层级 | 几级字号、是否加粗描边、是否用花字 | 层级数 |

### 1.2 爆款封面类型判定
- **痛点大字型**：整屏一句狠话，字号极大，无人物或少人物。适合观点、认知、避坑。
- **对比型**：左右/上下分屏，「before vs after」「错误 vs 正确」。适合教程、改造、效果展示。
- **清单型**：数字 + 罗列感（"5 个""3 步""全在这里"）。适合干货合集、工具盘点。
- **氛围型**：场景图为主，文字小而克制。适合生活方式、家居、旅行、穿搭。
- **真人出镜型**：人脸占主体，靠表情和身份建立信任。适合个人 IP、经验分享。
- **截图证据型**：聊天记录、后台数据、评论区截图。适合案例复盘、结果证明。

### 1.3 封面判断结论要回答的三个问题
1. 目标人群在 0.5 秒内能不能认出「这跟我有关」？
2. 它承诺了什么具体收益或规避了什么具体损失？
3. 这个封面能不能被同类笔记淹没？差异点在哪？

## 二、标题与内容结构拆解

### 2.1 标题拆解维度
- **钩子类型**：数字型 / 反差型 / 提问型 / 身份代入型 / 结果前置型 / 稀缺型 / 恐吓型。
- **关键词**：品类词、人群词、场景词、结果词各是什么，是否前置。
- **情绪强度**：平静陈述 → 轻度共鸣 → 强烈情绪（惊叹、愤怒、懊悔）。
- **读者定位**：写给谁（新手/宝妈/打工人/学生/同行），身份词是否出现。
- **字数与节奏**：总字数、断句数、是否有符号分隔（｜、·、/）。
- **承诺具体度**：有没有数字、时间、可验证的结果。

### 2.2 正文结构拆解维度
- **开头**（前 2 行）：是否复述痛点、抛出结论、制造悬念、建立身份。
- **主体框架**：总分总 / 清单式 / 时间线 / 问题-解决 / 对比论证。
- **分点方式**：数字编号、emoji 标记、空行分隔、小标题加粗。
- **段落长度**：每段几行，是否控制在手机一屏内可读。
- **信息密度**：观点多还是细节多，是否有可执行动作。
- **口语化程度**：书面语 / 半口语 / 强口语（"姐妹们""真的会谢"）。
- **话题标签**：几个、大词与长尾词配比、是否带品牌或活动标签。
- **结尾引导**：收藏、评论提问、关注、私信、评论区互动钩子。

### 2.3 输出要求
用「原文引用 + 判断」的方式写，例如：
> 标题：「月薪 5k 我也把出租屋改成了样板间」
> 钩子类型：身份代入 + 反差；关键词：月薪 5k（人群/收入）、出租屋（场景）、样板间（结果）；情绪：轻度反差爽感。

## 三、数据层面分析

### 3.1 互动结构指标
- **收藏/点赞比**：>0.6 通常说明「工具型/干货型」价值强，用户想存下来。
- **评论/点赞比**：>0.08 说明有争议点或强互动钩子；过低说明内容看完即走。
- **分享/点赞比**：>0.1 说明有社交货币属性（值得转给朋友）。
- **赞藏总量 vs 粉丝量**：远超粉丝量说明吃到了推荐流量，不是私域拉动。

### 3.2 判断口径
- 有精确数值：算出比值，对照上面区间给结论。
- 只有截图或"大概几万赞"：做定性评估（"收藏明显高于评论，偏工具型"），并标注置信度（高/中/低）。
- 数据缺失：只做内容层判断，明确写「数据未提供，以下为内容层推断」。

### 3.3 数据要回答的问题
1. 这篇是靠推荐流量还是靠粉丝？
2. 用户是「收藏备用」还是「情绪共鸣」还是「想讨论」？
3. 这个数据形态对创作者意味着什么（该复用哪种内容、该补哪个环节）？

## 四、模板提炼与输出格式

### 4.1 提炼原则
- 抽象到「结构」而非「原句」，但保留可感知的语气样本。
- 每个占位符只表达一件事，语义唯一。
- 模板要能换品类使用，标注「可迁移部分」和「不可迁移部分」。

### 4.2 输出格式（固定七段）
```
## 一句话结论
这篇之所以跑出来，核心是【__】。

## 1. 封面拆解
- 类型：【爆款封面类型】
- 构图/配色/焦点：【】
- 主标题原文：「」
- 有效点：【】
- 可迁移点：【】

## 2. 标题拆解
- 原文：「」
- 钩子类型：【】
- 关键词结构：【人群】+【场景】+【结果】
- 情绪与定位：【】

## 3. 正文结构拆解
- 开头手法：【】
- 主体框架：【】
- 排版节奏：【】
- 结尾引导：【】
- 话题标签：【】

## 4. 数据表现
- 已知数据：【】
- 互动结构：【收藏/点赞=__，评论/点赞=__】
- 判断：【】 置信度：【高/中/低】

## 5. 可复用模板
【封面模板】
主标题：______（痛点/结果，≤__字）
副标题：______（人群/条件限定）
视觉：______（配色 + 焦点 + 素材类型）

【标题模板】
______（人群/身份） + ______（场景/痛点） + ______（具体结果/数字）

【正文模板】
开头：______（复述痛点/抛结论）
第 1 点：______
第 2 点：______
第 3 点：______
结尾：______（引导动作）

【标签模板】
#______（大词） #______（长尾） #______（人群）

## 6. 仿写示范
（用模板填一份完整示例，可直接改）

## 7. 迁移建议
- 适合复用到：【品类/选题方向】
- 不建议照搬到：【场景】
- 下一篇优先验证：【变量】
```

### 4.3 多篇对比时的附加输出
- 逐篇拆解表（列：编号 / 封面类型 / 标题钩子 / 结构 / 数据形态 / 差异点）
- 共性规律 3-5 条，每条必须挂至少 2 篇的证据
- 一份聚合模板 + 各篇的差异化变体
